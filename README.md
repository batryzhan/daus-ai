# Daus AI / ТілОйын

**Ойна. Үйрен. Жең.**

🌐 **[Ойынды ашу — daus-ai.vercel.app](https://daus-ai.vercel.app/)**

Daus AI — қазақ тілін ұлттық ойындар арқылы қолдануға арналған веб-жоба. Ойыншылар тапсырмаларды орындап, сөздерді тәжірибеде қолданады, бір-біріне қазақша нұсқау береді және жауаптарын тексереді.

Жоба балаларға, ата-аналарға және сабақта ойын элементтерін пайдаланғысы келетін педагогтерге арналған. Ойын ережелері ұлттық ойындардан шабыт алып, осы жобаға бейімделген.

## Ойындар

### Асық ату — досыңды бағытта

Екі ойыншы бір құрылғыны кезекпен пайдаланады. Бірінші ойыншы нысанаға қарап, досына қазақша нұсқау береді. Екінші ойыншы нұсқауды оқып, сәйкес асықты таңдайды. Раунд соңында нәтиже мен тілдік кері байланыс көрсетіледі.

Ойын түстерді, орын мен бағытты білдіретін сөздерді қолдануға көмектеседі. Асықтарды ойын алаңында жылжытуға, ал таңдауды түймелер арқылы жасауға болады.

### Бәйге

Бес сұраққа жауап беріп, мәреге жетіңіз. Дұрыс жауап аттың жүрісін жылдамдатады. Жарыс соңында дұрыс жауаптар саны көрсетіледі.

## Дауыспен жауап беру

Микрофонға рұқсат беріп, қазақша сөйлей аласыз. Танылған мәтінді қолданар алдында тексеруге және түзетуге болады. Микрофон немесе дауыс қызметі қолжетімсіз болса, мәтінді қолмен енгізіңіз.

## Жергілікті іске қосу

Node.js 20 немесе одан жаңа нұсқасы қажет.

1. Тәуелділіктерді орнатыңыз: `npm install`.
2. `.env.example` файлын `.env` атауымен көшіріңіз.
3. Дауысты тану үшін `.env` файлына `ALEM_API_KEY`, ал тілдік талдау үшін `GROQ_API_KEY` енгізіңіз. Кілттерді репозиторийге қоспаңыз. Оларсыз негізгі ойын қолжетімді, ал тиісті қосымша қызметтер жұмыс істемейді.
4. `npm run dev` пәрменін орындаңыз.
5. Браузерде [http://localhost:5173](http://localhost:5173) мекенжайын ашыңыз.

Жинақты тексеру үшін `npm run build`, ал жинақталған нұсқаны іске қосу үшін `npm start` пәрменін пайдаланыңыз.

## Модельдер

Асық алаңында `assets/3d-files/Asyk.glb` моделі қолданылады. Бәйге ойынындағы `public/models/Horse.glb` — [Three.js мысалдарындағы ат моделі](https://threejs.org/examples/models/gltf/Horse.glb). 3D көрініс қолжетімсіз болған жағдайда ойынға арналған балама көрсетіледі.

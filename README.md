# Daus AI

Қазақ тілін ойын кезіндегі қарым-қатынас құралы ететін шағын веб-ойын. MVP-де асық атуға шабыттанған «Досыңды бағытта» ойыны бар. Цифрлық ережелер осы жобаға арнап жасалған.

## Жергілікті іске қосу

1. Node.js 20+ орнатыңыз.
2. `npm install`
3. `.env.example` файлын `.env` деп көшіріңіз. Серверлік AI талдауы үшін `GROQ_API_KEY` енгізіңіз; кілтсіз негізгі ойын ойнай береді.
4. `npm run dev` командасын орындаңыз.
5. Frontend: http://localhost:5173 · API: http://localhost:3000/api/health

Production тексерісі мен іске қосу: `npm run build`, содан соң `npm start`. Сервер API-мен бірге `dist` frontend каталогын да береді және `PORT` портын тыңдайды. Бір origin-де frontend/backend орналастырыңыз. Бөлек домен қолдансаңыз, `CORS_ORIGIN` айнымалысына рұқсат етілген origin-дерді үтірмен бөліп енгізіңіз.

## Айнымалылар

- `PORT`: API серверінің порты (әдепкісі 3000)
- `CORS_ORIGIN`: рұқсат етілген frontend origin-дері (әдепкіде CORS ашық; production-та нақты доменді көрсетіңіз)
- `GROQ_API_KEY`: Groq серверлік кілті
- `GROQ_LLM_MODEL`: Groq арқылы қолжетімді GPT-OSS моделі (әдепкісі `openai/gpt-oss-120b`)
- `GROQ_STT_MODEL`: болашақ STT моделі (әдепкісі `whisper-large-v3`)
- `AZURE_SPEECH_KEY`, `AZURE_SPEECH_REGION`: болашақ Azure Speech интеграциясы

## MVP құрамында

- Бір телефонға арналған екі ойыншының кезектескен сценарийі: мақсатты көру, телефонды беру, қазақша нұсқау, жауапты таңдау.
- Раунд пен ұпайды сервердегі кәдімгі логика тексереді; AI ұпайға ықпал етпейді.
- Groq GPT-OSS арқылы ойыннан кейінгі қысқа тілдік пікір. API бапталмаса/қате берсе, ойын жалғасады.
- Талдауға минутына 12 сұраным шегі және 12 секундтық API timeout.
- Жауап кілті мен есеп in-memory сақталады. Сервер қайта іске қосылғанда ағымдағы раунд жоғалады.

## Әзірге жоқ

Дауыс жазу/STT, Azure TTS, онлайн мультиплеер, аккаунт/сақталатын статистика және басқа ойындар. Қоғамдық URL жасалып, тексерілген жоқ. Қазақша UI мен жобаға арналған мысалдарды демо алдында қазақ тілін жақсы білетін адам тексеруі керек.

## 3D асық моделі

`assets/3d-files/Asyk.glb` түпнұсқасы сол орнында қалады және Vite-тің `?url` импортымен production bundle-ға қосылады. Бір 3D көріністе модель бірнеше рет көшіріліп, таңдау кезінде қысқа айналу/секіру анимациясын орындайды. WebGL немесе жүктеу істемесе, асық пішініндегі SVG белгісі мен ойынның HTML түймелері қолжетімді болып қалады.

Бәйге: Horse.glb — модель из примеров Three.js (https://threejs.org/examples/models/gltf/Horse.glb), локальная копия `public/models/Horse.glb`. Ответы меняют скорость анимации; прогресс определяется числом вопросов.
